## FAQ

### Are wireless security systems reliable?
**Yes.** Modern wireless systems use encrypted communication, cellular backup, and long-lasting batteries. Reliability equals hardwired systems.

### Do I need professional monitoring?
**Not necessarily.** Self-monitoring works well if you're responsive to alerts. Professional monitoring provides peace of mind and guaranteed emergency response.

### How much does a home security system cost?
**DIY systems:** $200-$1,000 upfront + $0-$30/month
**Professional systems:** $500-$1,500 upfront + $30-$45/month

### Can I install security systems myself?
**Yes, most systems are DIY-friendly.** SimpliSafe, Ring, Abode, and others install in under an hour. Professional installation is available from ADT, Vivint, etc.

### Do smart locks work during power outages?
**Yes.** Most smart locks run on batteries and work independently of home power. Some include key backups.

### Are security cameras worth it?
**Absolutely.** Cameras deter crime, provide evidence, and enable remote monitoring. Video doorbells alone have reduced package theft by 40%+.

### Can I take my security system when I move?
**Yes.** DIY systems are easily moved. Professional systems may require reinstalling at new location (some companies offer relocation deals).
