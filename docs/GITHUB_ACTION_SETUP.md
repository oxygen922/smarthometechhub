# 自动文章生成系统配置指南

## 🚀 功能概述

SmartHome TechHub 的自动化文章生成系统使用 GitHub Actions 每天自动生成和发布智能家居评测文章。

### 📅 生成时间

- **默认时间**: 每天 UTC 0:00（北京时间 8:00 AM）
- **手动触发**: 可通过 GitHub Actions 页面手动触发

### 📊 生成策略

| 文章总数 | 每日生成数量 | 频率 |
|---------|-------------|------|
| 0-1000篇 | 每个分类5篇 | 高频 |
| 1000篇+ | 每个分类1篇 | 低频 |

**计算**: 7个分类 × 5篇 = 每天35篇（高频）/ 每天7篇（低频）

## 🔧 配置步骤

### 第一步：配置 GitHub Secrets

进入 GitHub 仓库 → Settings → Secrets and variables → Actions → New repository secret

添加以下 API 密钥：

```
DEEPSEEK_API_KEY
- 你的 DeepSeek API 密钥
- 获取地址: https://platform.deepseek.com/
- 示例: sk-adcc3f4770774b578c6dfa634a84c18b

UNSPLASH_ACCESS_KEY
- 你的 Unsplash API 密钥
- 获取地址: https://www.unsplash.com/developers
- 示例: hXbt9uQSD4KIADmHXGltaCYc_cFBKo2v872QXexm6As

PEXELS_API_KEY
- 你的 Pexels API 密钥（可选）
- 获取地址: https://www.pexels.com/api/
- 如不需要可留空

PIXABAY_API_KEY
- 你的 Pixabay API 密钥（可选）
- 获取地址: https://pixabay.com/api/docs/
- 如不需要可留空

R2_ACCOUNT_ID
- Cloudflare R2 账户ID
- 获取地址: Cloudflare Dashboard → R2 → Overview → Account ID
- 示例: ceec996a81ee29acc1eb188b0a2017e4

R2_ACCESS_KEY_ID
- Cloudflare R2 访问密钥ID
- 获取地址: Cloudflare Dashboard → R2 → Manage R2 API Tokens
- 示例: 31f8b4b7cc071581d466b7f02b4877e3

R2_SECRET_ACCESS_KEY
- Cloudflare R2 密钥
- 获取地址: 同上，创建Token时生成
- 示例: 009fcc6f48824ba0bae703d97d345c9c8cd480d553fa7c1000a19988da02a422

R2_BUCKET_NAME
- Cloudflare R2 存储桶名称
- 获取地址: Cloudflare Dashboard → R2 → 你的存储桶名称
- 示例: autoblog

R2_PUBLIC_URL
- Cloudflare R2 公共访问URL
- 获取地址: Cloudflare Dashboard → R2 → 你的存储桶 → Settings → Public URL
- 示例: https://pub-a6a4ae7f5151464cb2be257af37faafe.r2.dev
```

### 第二步：启用 Actions

1. 将代码推送到 GitHub
2. 进入 **Actions** 标签页
3. 如果是第一次使用，点击 **I understand my workflows, go ahead and enable them**

### 第三步：验证配置

运行一次手动测试：

1. 进入 **Actions** → **Daily Article Generation**
2. 点击 **Run workflow**
3. 选择每个分类生成的文章数（默认5篇）
4. 点击 **Run workflow** 开始
5. 观察运行日志确保成功

## 🛠️ 工作流程说明

### 自动执行流程

```
1. 检查当前文章数
   ↓
2. 判断生成频率（≥1000篇则降低频率）
   ↓
3. 安装Python和Node.js依赖
   ↓
4. 生成文章（每个分类指定数量）
   ↓
5. 更新前端JSON数据
   ↓
6. 一次性提交所有更改到GitHub
   ↓
7. 生成报告（新增文章数）
```

### 提交格式

```
feat: daily article generation - 2026-05-13

✅ Generated new articles
📊 Total articles: 523
🤖 Auto-generated by GitHub Actions

[skip-ci]
```

### 修改生成时间

如需修改运行时间，编辑 `.github/workflows/daily-article-generation.yml`：

```yaml
on:
  schedule:
    # UTC 时间，例如：
    # 0 0 * * * = 每天 00:00 UTC
    # 0 12 * * * = 每天 12:00 UTC
    # 0 4 * * * = 每天 04:00 UTC (北京时间中午12:00)
    - cron: '0 0 * * *'
```

## 📝 手动触发工作流

### 通过 GitHub UI

1. 进入 **Actions** → **Daily Article Generation**
2. 点击 **Run workflow**
3. 选择每个分类的文章数
4. 点击 **Run workflow**

### 通过 GitHub CLI

```bash
gh workflow run daily-article.yml \
  -f articles_per_category=5
```

### 修改默认文章数

在工作流文件中修改默认值：

```yaml
inputs:
  articles_per_category:
    default: '5'  # 改为 '1', '3', 或 '5'
```

## 🚨 故障排查

### 工作流运行失败

**检查清单**：
1. ✅ Secrets 是否正确配置
2. ✅ API 密钥是否有效
3. ✅ 依赖安装是否成功
4. ✅ 文件路径是否正确

**查看日志**：
- 点击失败的运行记录
  - 查看每个步骤的详细日志
  - 常见错误：API密钥无效、依赖安装失败

### 没有生成新文章

**可能原因**：
1. API调用失败 - 检查日志中的错误信息
2. 图片搜索失败 - 查看 Unsplash/Pexels API 状态
3. 配额限制 - 检查 API 密钥的配额

### 文章未推送到 GitHub

**检查**：
1. 是否有 `GITHUB_TOKEN` secret 配置
2. 是否有写权限
3. 分支保护规则是否允许 Actions 提交

## 📊 监控和统计

### 查看生成进度

1. 进入 **Actions** → **Daily Article Generation**
2. 查看 **Run history**
3. 每次运行会显示：
   - 当前文章数
   - 新增文章数
   - 生成状态

```bash
node -e "const data=require('./lib/articles-data.json'); console.log(data.length);"

# 每个分类的文章数
node -e "const data=require('./lib/articles-data.json'); const cats={}; data.forEach(a=>cats[a.category]=(cats[a.category]||0)+1); console.log(cats);"
```

## 🔄 回滚和恢复

### 如果生成的文章有问题

1. 进入 **Actions** → **Runs**
2. 找到成功的工作流运行
3. 记录 **commit SHA**
4. 使用 `git revert` 或 `git reset` 回滚

### 禁用自动生成

临时停止：
- 进入仓库 **Settings** → **Actions** → **General**
- 点击 **Disable workflows**

永久删除：
- 删除 `.github/workflows/daily-article-generation.yml` 文件

## 📈 优化建议

### API 使用优化

1. **监控 API 配额**
   - 定期检查各 API 的剩余配额
   - 在 GitHub Secrets 中记录配额信息

2. **错误处理**
   - 工作流已包含错误处理
   - 失败时不会提交错误的更改

### 生成策略优化

1. **关键词多样性**
   - 每个分类有 7 个不同关键词
   - AI 为每篇文章生成独特搜索词

2. **图片去重**
   - 记录已使用的图片 URL
   - 自动避免重复

3. **质量保证**
   - 每篇文章 1500-2000 字
   - 包含技术规格表格
   - 专业评测内容
