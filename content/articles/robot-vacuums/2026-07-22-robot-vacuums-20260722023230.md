**LiDAR vs. Camera Navigation:** LiDAR-based systems (Samsung, Roborock) map rooms faster and work in complete darkness. Camera-based systems (iRobot) can recognize specific objects but struggle in low light.

## Installation & Smart Home Integration

### Setup Process

All three models follow a similar setup process:

1. **Unboxing:** Remove all packaging, including tape on sensors and brushes.
2. **Dock Placement:** Position the dock against a wall with 3 feet of clearance on each side. Ensure the dock is on a hard, level surface.
3. **App Installation:** Download the respective app (SmartThings, Roborock, iRobot Home) and create an account.
4. **Wi-Fi Connection:** Connect the vacuum to your 2.4GHz Wi-Fi network (5GHz is not supported).
5. **Initial Mapping:** Allow the vacuum to complete a "Quick Map" or "Explore" run. This takes 10-20 minutes depending on home size.
6. **Customization:** Set no-go zones, room names, and cleaning schedules. Enable smart home integrations.

### Smart Home Integration Tips

**Samsung SmartThings Users:** Create routines like "Good Morning" that triggers the vacuum to clean the kitchen and living room while you're having coffee. Use the SmartThings presence sensor to automatically start cleaning when everyone leaves.

**Amazon Alexa Users:** Enable the "Alexa, ask [brand] to clean the kitchen" skill. Set up routines like "Alexa, I'm leaving" to trigger a full-home clean.

**Google Home Users:** Use voice commands like "Hey Google, start vacuuming" or "Hey Google, vacuum the living room." Create morning routines that include vacuuming.

**Apple HomeKit Users:** The iRobot and Samsung offer native HomeKit support. Create automations like "When the last person leaves, start cleaning" or "When I arrive home, stop cleaning."

### Maintenance Schedule

- **Weekly:** Empty the dustbin (if not using auto-empty), clean the brush roll, and wipe sensors.
- **Monthly:** Clean the filter, check for hair tangles, and inspect the mopping pad.
- **Quarterly:** Deep clean the dock, replace the filter, and lubricate wheel axles.
- **Annually:** Replace the battery (if needed), update firmware, and inspect all moving parts.
