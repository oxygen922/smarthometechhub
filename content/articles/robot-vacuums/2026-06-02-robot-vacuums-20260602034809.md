## Installation & Smart Home Integration

### Unboxing and Setup
All three models come with clear instructions. Setup takes 10–15 minutes:
1. **Download the app** (iRobot Home, Roborock, or EufyHome).
2. **Connect to Wi-Fi** (2.4 GHz only for most models—ensure your router supports it).
3. **Place the charging base** against a wall with at least 3 feet of clearance on each side.
4. **Let the robot map your home** (first run is exploratory—don’t intervene).

### Smart Home Integration Tips
- **Alexa/Google Assistant:** Use voice commands like “Alexa, tell Roomba to clean the kitchen.” All three support this.
- **Apple HomeKit:** Only the iRobot j9+ supports HomeKit. If you’re deep in the Apple ecosystem, this is a strong selling point.
- **Routines:** Set up automations—for example, have the vacuum run when you leave for work (using geofencing).

### Common Pitfalls to Avoid
- **Don’t place the base in direct sunlight**—it can interfere with charging.
- **Check for low furniture**—the Roborock S8 is 3.8 inches tall; it may not fit under some sofas.
- **Update firmware immediately**—manufacturers often release critical navigation improvements.
