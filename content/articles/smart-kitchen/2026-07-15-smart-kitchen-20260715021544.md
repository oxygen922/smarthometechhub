## Installation & Smart Home Integration

### Installation Requirements

**Countertop Ovens (June, Breville):**
- Requires standard 120V outlet (15-amp circuit recommended)
- No professional installation needed
- Allow 4 inches of clearance on all sides for ventilation
- Place on heat-resistant surface away from cabinets

**Built-In Ovens (GE Profile):**
- Requires 240V dedicated circuit (30-amp minimum)
- Professional installation by licensed electrician is mandatory
- Must fit into standard 30-inch cabinet opening
- May require additional ventilation if installed under cooktop
- Consider trim kits for seamless integration with cabinetry

### Smart Home Ecosystem Compatibility

All three ovens support major smart home platforms:

- **Amazon Alexa:** Voice commands for preheating, setting timers, and checking cooking status
- **Google Assistant:** Similar functionality with Google Home devices
- **Apple HomeKit:** Only the GE Profile offers limited HomeKit integration (on/off control)
- **IFTTT:** June Oven supports custom automation recipes (e.g., “If I arrive home, preheat the oven”)
- **Zigbee/Z-Wave:** None of these ovens natively support these protocols, but you can use smart plugs for basic on/off control (not recommended for safety)

### Integration Tips

1. **Create Cooking Routines:** Use Alexa Routines to automatically preheat your oven when you say “Alexa, I’m home for dinner.”
2. **Sync with Meal Planning Apps:** June Oven’s API allows integration with apps like Mealime and Yummly for one-tap cooking.
3. **Use Smart Plugs with Caution:** Only use smart plugs rated for high-wattage appliances (15A minimum) and never leave the oven unattended when controlled remotely.
4. **Enable Notifications:** Set up push notifications for cooking completion, temperature alerts, and maintenance reminders.
