## Installation & Smart Home Integration

### Installation Tips
- **DIY Systems (SimpliSafe, Ring):** Installation takes 30–60 minutes. Use the included adhesive strips or screws to mount sensors on doors and windows. Place the base station in a central location for optimal Wi-Fi/cellular reception. Test each sensor before finalizing placement.
- **Professional Systems (ADT):** ADT sends a technician who will install all components, run wiring if needed, and show you how to use the panel. Expect 2–4 hours for a typical home. Make sure to be present during installation to ask questions.

### Smart Home Integration
**SimpliSafe NextGen Pro:** Works with Alexa, Google Assistant, and Apple HomeKit. You can create routines like “Arm when I leave” using geofencing. The system also integrates with Philips Hue lights and August locks.

**Ring Alarm Pro:** Deep integration with Alexa means you can arm/disarm by voice, view camera feeds on Echo Show devices, and trigger routines. Supports Z-Wave and Zigbee devices (lights, locks, thermostats). No native Google Home or HomeKit support without third-party bridges.

**ADT Command Plus:** Uses Z-Wave and Zigbee protocols, so it works with hundreds of smart devices (e.g., Yale locks, Lutron lights, Nest thermostats). Voice control is limited to Alexa via a separate skill. The touchscreen panel can control all connected devices.

**Pro Tip:** For a truly integrated smart home, choose a system that supports a wide range of protocols (Z-Wave, Zigbee, Wi-Fi) and voice assistants. SimpliSafe offers the broadest compatibility, while Ring is best for Alexa users.
